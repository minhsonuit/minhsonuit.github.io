Nguyên tắc Bất khả xâm phạm trong Kiến trúc & Tích hợp AX

Bộ quy chuẩn kỹ thuật bắt buộc được áp dụng xuyên suốt mọi dự án tích hợp ERP nhằm bảo vệ toàn vẹn dữ liệu và chống sập hệ thống lõi.

RULE 01 Mandatory

AX Adapter Độc quyền

AX Adapter là điểm duy nhất được phép gọi vào AX. Mọi ứng dụng vệ tinh (Web, App, POS, 3PL) bắt buộc phải giao tiếp qua lớp Adapter chuẩn hóa, không kết nối phân tán.

RULE 02 Strict Write Ban

Cấm Ghi Trực tiếp AX SQL

Cấm tuyệt đối write trực tiếp vào AX SQL Server. Mọi thao tác thêm/sửa/xóa phải đi qua tầng nghiệp vụ AX để bảo toàn `RecId`, `RecVersion`, bộ đệm AOS và tính toàn vẹn kế toán.

RULE 03 Fallback Only

SQL AX Chỉ Cho Read-Only Fallback

SQL Server AX chỉ phục vụ Read-Only Fallback hoặc truy vấn báo cáo tách luồng trên bản sao (Read Replica), không làm ảnh hưởng đến hiệu năng giao dịch OLTP.

RULE 04 100% Safe SQL

Truy vấn Parameterized

100% Query Parameterized, cấm hoàn toàn dynamic string SQL. Loại bỏ triệt để nguy cơ SQL Injection và giúp SQL Server tái sử dụng Execution Plan hiệu quả (chống Plan Cache Bloat).

RULE 05 Resilience

Timeout + Circuit Breaker Bắt buộc

Mọi kết nối tích hợp bắt buộc cấu hình Timeout & Circuit Breaker. Tự động ngắt mạch cô lập lỗi khi dịch vụ đích chậm, ngăn chặn hiệu ứng sập dây chuyền (Cascading Failure).

RULE 06 ACID & Audit

Đối soát & Toàn vẹn Dữ liệu

Mọi giao dịch bán lẻ và tài chính đều gắn mã định danh duy nhất (Idempotency Key), đảm bảo đối soát khớp 100% giữa POS, Kho và Sổ cái.
